The leras verify-hygiene sweeps converged on three reusable shapes for
tasks with no code anchor, now proven across 19 tasks (4e5b1f04):

1. umbrella → zero-open-children `q` count (the gid JOIN);
2. owner/relay-gated hold → grep for a hand-written dated marker log
   line (date-first, so CLI T-stamped comments stay inert);
3. artifact task → a verify that prescribes the artifact filename,
   doubling as the naming contract.

Teach them under a "close-condition shapes" heading so the next
adopter's store doesn't need two gardening sessions to rediscover
them. Pairs with mw-8kfqz2z (the traps are what these shapes avoid).
