*authored* wholesale via Write because `add` takes only a title and the
skill never states the layout rule. Prevent the class in the skill:

- one loud line — body prose goes ABOVE `## log`/`## comments`; the
  tail sections end the file; never append prose to the end of a task
  file;

  one-document `add --batch`, not a hand-written file.

Skill installs per-repo, so adopted repos pick this up on their next
skill refresh.
